?? คู่มือระบบ Aonang Fiore HRMS (SmartHR Phase 1)
?? โครงสร้างไฟล์ในระบบ
เพื่อให้โปรแกรมทำงานได้สมบูรณ์ ในโฟลเดอร์จะต้องมีไฟล์เหล่านี้:
1.	database.py - สมองกลจัดการฐานข้อมูล (ลิ้นชักเก็บข้อมูล)
2.	main.py - ระบบหลังบ้าน (API) สำหรับคำนวณเงินเดือน
3.	frontend.py - หน้าเว็บสำหรับให้ HR และบัญชีใช้งาน
4.	Start_HRMS.bat - สคริปต์สำหรับดับเบิ้ลคลิกเพื่อเปิดโปรแกรม (ทั้งหน้าเว็บและหลังบ้าน)
5.	THSarabunNew.ttf และ THSarabunNew Bold.ttf - ไฟล์ฟอนต์ภาษาไทย (สำหรับออกเอกสาร PDF)
6.	logo.png หรือ logo.jpg - โลโก้รีสอร์ท (สำหรับโชว์หน้าล็อคอิน)
7.	payroll.db - ไฟล์ฐานข้อมูล (ระบบจะสร้างให้อัตโนมัติเมื่อรันโปรแกรม ห้ามลบหากมีข้อมูลจริงอยู่)

?? รูปแบบไฟล์ Excel สำหรับอัปโหลด
1. ไฟล์นำเข้า "ฐานข้อมูลพนักงาน" (แท็บ 1)
ต้องมีหัวคอลัมน์ภาษาอังกฤษเรียงตามนี้ (ตัวพิมพ์เล็ก):
•	emp_code : รหัสพนักงาน (ห้ามซ้ำ)
•	first_name : ชื่อจริง
•	last_name : นามสกุล
•	position : ตำแหน่ง
•	department : แผนก
•	phone : เบอร์โทรศัพท์
•	start_date : วันเริ่มงาน (เช่น 2026-03-01)
•	address : ที่อยู่
•	tax_info : ข้อมูลลดหย่อนภาษี
•	base_salary : ฐานเงินเดือน (ตัวเลขเท่านั้น)
•	account_no : เลขบัญชีธนาคาร
•	is_sso : ใส่ TRUE (ถ้าหักประกันสังคม) หรือ FALSE (ถ้าไม่ต้องหัก)
2. ไฟล์นำเข้า "ข้อมูลรายรับ-รายจ่าย (OT/สาย/ลา)" (แท็บ 2)
ต้องมีหัวคอลัมน์ภาษาอังกฤษเรียงตามนี้ (ตัวพิมพ์เล็ก):
•	emp_code : รหัสพนักงาน (สำคัญที่สุด ต้องตรงกับในฐานข้อมูล)
•	emp_name : ชื่อพนักงาน (ระบบไม่อ่านช่องนี้ ใส่ไว้ให้ HR ดูง่ายๆ)
•	ot_15_hours : จำนวนชั่วโมง OT 1.5 เท่า
•	ot_1_hours : จำนวนชั่วโมง OT 1.0 เท่า (วันหยุด)
•	late_mins : จำนวนนาทีที่มาสาย
•	absent_days : จำนวนวันที่ขาดงาน
•	leave_hours : จำนวนชั่วโมงที่ลางานแบบหักเงิน
•	other_benefits : สวัสดิการ/รายรับอื่นๆ
•	backpay : เงินตกเบิก/เงินเดือนย้อนหลัง
•	company_loan : ยอดหักหนี้สินบริษัท
•	student_loan : ยอดหัก กยศ.

??? การแก้ไขปัญหาเบื้องต้น (Troubleshooting)
•	อัปโหลด Excel แล้ว Error: ให้ตรวจสอบ "ชื่อหัวคอลัมน์" ว่าพิมพ์ถูกเป๊ะๆ หรือไม่ และห้ามมีช่องว่างหรือเว้นวรรคแปลกๆ ซ่อนอยู่
•	ยอด OT เป็น 0: เช็คไฟล์ Excel ให้ชัวร์ว่าหัวคอลัมน์เป็น ot_15_hours และ ot_1_hours ไม่ใช่ชื่ออื่น
•	อยากล้างข้อมูลทั้งระบบเริ่มใหม่: ให้ปิดโปรแกรม (ปิดหน้าจอดำ) แล้วไปลบไฟล์ payroll.db ทิ้ง จากนั้นเปิดโปรแกรมใหม่ ระบบจะสร้างลิ้นชักเปล่าๆ ให้ใหม่ทั้งหมด (พนักงานและประวัติการจ่ายเงินจะหายหมด)
•	ลืมรหัสผ่าน Admin: เปิดไฟล์ frontend.py ค้นหาคำว่า admin แล้วเปลี่ยนรหัส 13579 ในบรรทัดนั้นเป็นรหัสใหม่ได้เลย
